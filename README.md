# Aurelle Studio - Luxury Salon & Spa Frontend

A luxury editorial beauty & wellness website built with React, TypeScript, Vite, and Tailwind CSS.

## Features
- **Editorial Luxury Aesthetic**: Warm ivory (`#FAF7F2`), champagne, blush rose, and deep burgundy palette with Playfair Display / Cormorant Garamond typography.
- **Interactive Booking Engine**: Form with validation for guest details, services, date restrictions, time slots, and stylist selection with demo pass generation (`#AUR-xxxx`).
- **Interactive Modals**:
  - Service detail modals with pricing in INR, inclusions, and benefits.
  - Curated beauty packages with instant discount tags.
  - Stylist expert profile drawers with portfolio details.
  - High-definition before-and-after transformation lightbox.
  - 360° Studio Ambience tour modal.
  - ReSolution Agency "Want a Website Like This?" conversion modal with WhatsApp direct connect.
- **Mobile Responsive**: Mobile navigation drawer, responsive grids, touch-friendly inputs.
